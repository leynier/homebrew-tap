# Homebrew tap for Alera

[Alera](https://alera.build) is a native, performance-first agentic development environment.

```bash
brew tap leynier/tap
brew install --cask alera
```

Requires Apple Silicon and macOS 14 or newer.

The cask clears the `com.apple.quarantine` attribute after installing, because the macOS build is not notarized yet. Homebrew quarantines what it downloads, so without that step Gatekeeper refuses to open the app.

Alera does not update itself when Homebrew owns the installation. Settings shows `brew upgrade --cask alera` and can run it for you.

`Casks/alera.rb` is generated by the Alera release workflow from `packaging/homebrew/alera.rb.tmpl` in [leynier/alera](https://github.com/leynier/alera). Send changes there, not here.
